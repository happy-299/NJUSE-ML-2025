## Review Comment
```
{comment}
```

---

## Your Task
Based on the review comment, identify which specific lines in the NEW code need to be modified.

Consider:
1. What is the reviewer pointing out?
2. Which parts of the code change are problematic?
3. What lines need to be fixed to address the comment?

Provide your answer in the specified JSON format with:
- `line_indices`: List of 0-based line numbers (in the NEW code)
- `confidence`: Your confidence level
- `reasoning`: Step-by-step explanation
- `affected_code`: Brief description

---

# Few-shot Examples (for reference)

## Example 1
**Review Comment**: "Missing error handling for file operations"

**Code Diff**:
```diff
@@ -1,3 +1,4 @@
 def read_config():
-    return json.load(open('config.json'))
+    f = open('config.json')
+    return json.load(f)
```

**Response**:
```json
{
    "line_indices": [1, 2],
    "confidence": 0.95,
    "reasoning": "The reviewer points out missing error handling. Lines 1-2 (opening file and loading JSON) both need try-except blocks to handle potential IOError and JSONDecodeError.",
    "affected_code": "File opening and JSON loading operations"
}
```

## Example 3

```diff
@@ -1,5 +1,7 @@

-    conn = create_connection()
-    result = conn.execute(sql)
-    conn.close()
+    conn = create_connection()
+    try:
+        result = conn.execute(sql)
+    finally:
+        conn.close()
     return result
```

**Response**:
```json
{

    "confidence": 0.90,

    "affected_code": "Database connection and query execution logic"
}
```
